PowerPointにAIアドインを入れる

第4回では、PowerPointの中でAIに手を動かしてもらいます。そのための準備を、当日までにお願いします。一度入れれば、次からはPowerPointを開くだけで使えます。

所要 5分ほど 本編は35分 2026年8月時点の手順

入れられなくても参加できます。claude.ai や ChatGPT にファイルを貼る形での進め方も用意しています。うまくいかない方は、無理せずそのままお越しください。当日やることは同じです。

第3回でExcelに入れた方へ

新しく入れ直す必要は、ほぼありません。PowerPointを開いて、「ホーム」タブの右端に Claude か ChatGPT のアイコンが出ているか見てください。出ていれば、それで準備完了です。

Claude版は Excel・PowerPoint・Word が1つのアドインに入っているので、Excelに入れた時点でPowerPointにも入っています。ChatGPT版も同じでした。

PowerPointを開いたままだとアイコンが出てこないことがあります。いったん閉じて開き直してから確認してください。出ていなければ、下の STEP 1 から入れ直せます。同じ手順です。

③ Microsoftアカウント

アドインはMicrosoftのストアから入れるので、途中でMicrosoftアカウントへのサインインを求められます（Claude版・ChatGPT版どちらも）。

  • Microsoft 365版のPowerPointをお使いなら、すでにお持ちのアカウント（PowerPointにサインインしているもの）でそのまま入れます
  • 会社のPCなら、職場・学校のアカウントでも入れます
  • お持ちでない場合は、無料で作れます。サインイン画面の「作成」から進んでください

使っているアカウントが分からないときは、PowerPointの「ファイル」→「アカウント」に表示されています（②で見た画面と同じところです）。

STEP 1-AClaude for Microsoft 365 を入れる

ChatGPT版を入れる方は STEP 1-B へ。

A-1. Microsoft マーケットプレイス のページを開く

下のリンクから「Claude for Microsoft 365」のページを開きます。

https://marketplace.microsoft.com/en-us/product/office/WA200010725?tab=Overview

リンクが開かない場合は、Microsoft マーケットプレイス で「Claude」と検索してください。作成者が「Claude by Anthropic for Office」になっているものが目印です。

A-2. 「今すぐ入手」をクリック

「今すぐ入手」ボタンを押します。Microsoftアカウントへのサインインを求められるので、サインインしてください（STEP 0 の③）。

ボタンの左に「価格　追加購入が必要になる場合があります」と出ていますが、ここで課金は発生しません。 Claudeの有料プランが別に必要という意味です（STEP 0 の①）。

A-3. 名前と国を入力する

次のページで名前・国などを聞かれるので、入力して、もう一度「今すぐ入手」をクリックします。完了画面が出れば、インストールは終わりです。

STEP 2 へ進む →

STEP 1-BChatGPT を入れる

Claude版を入れた方は STEP 2 へ。

探すのは「ChatGPT」です。似た名前の別物がたくさんあります
検索すると Ghostwriter / GPT for PowerPoint / CoreGPT AI for PowerPoint など、名前の似たアドインがいくつも並びます。
入れるのは、名前が「ChatGPT」だけ・提供元が「OpenAI合同会社」（または OpenAI, LLC）のものです。アイコンは黒い結び目のようなマーク。
名前が詳しいほうが正しそうに見えますが、逆です。

B-1. PowerPointの「ホーム」→「アドイン」から探す

PowerPointを開いて、「ホーム」タブ →「アドイン」→ 検索バーに「ChatGPT」と入力 →「追加」。

※「ファイル」でも「挿入」でもなく、「ホーム」タブです。

B-2. マーケットプレイスから入れることもできます

下のリンクからでも入れられます。

https://marketplace.microsoft.com/en-us/product/office/wa200010215?tab=overview

タイトルの下が「OpenAI合同会社による」になっていることを確認して、「今すぐ入手」を押します。Microsoftアカウントへのサインインを求められるので、サインインしてください（STEP 0 の③。職場・学校アカウントでも可）。

ボタンの左に「価格　追加購入が必要になる場合があります」と出ていますが、ここで課金は発生しません。 ChatGPTは無料プランでも使えます。

STEP 2 へ進む →

STEP 2PowerPointでAIを開く

2-1. PowerPointを起動する

すでにPowerPointを開いていた方は、いったん閉じてから開き直してください。開いたままだとアドインが出てこないことがあります。

2-2. ホームタブのアイコンをクリック

ホームタブのいちばん右に、入れたアドインのアイコン（「Claude」または「ChatGPT」）が出ています。クリックすると、画面の右側にパネルが開きます。

アイコンが見当たらないとき
すぐ左の「アドイン」ボタン →「マイアドイン」の中にあります。そこから開いてください。（Macの場合は「ツール」→「アドイン」）

STEP 3サインインする

いつも使っているアカウントでサインインします。押すボタンの名前が、Claude版とChatGPT版で違います。

Claude版

右側に開いたパネルの「Sign in（サインイン）」を押して、claude.ai と同じアカウントでサインインします。

サインインが済んで、パネルの下に入力欄が出れば準備完了です。

ChatGPT版（画面が続けて出ます）

ChatGPT版は、サインインのあとに確認画面が2つ続きます。少し長く感じますが、全部進めて大丈夫です。

  1. パネルの「ChatGPT で続行」（黒いボタン）を押す
    その下の「API キーを使用」は押さないでください。別の（有料の）使い方の入口です
  2. ログイン画面が開くので、chatgpt.com と同じアカウントでログイン
    Google・Apple・Microsoftのアカウントでも入れます
  3. 「利用規約とプライバシー」→「理解して同意する」を押す
  4. 紹介画面が出たら「次へ」か「スキップ」を押す

パネルが「新規チャット」と書かれた空の状態になれば、準備完了です。

STEP 4動作確認（1分でできます）

ちゃんと動くか、ここで一度だけ試してみてください。Claude版・ChatGPT版どちらでも同じです。

  1. PowerPointで新しいプレゼンテーションを作ります（白紙で構いません）
  2. スライドを1枚表示した状態で、パネルに次の一文を貼って送ります

スライドのタイトルに「テスト」と入力してください

スライドのタイトルに「テスト」と入れば、当日そのまま使えます。ここまで確認できていれば大丈夫です。

戻したいときは、PowerPointの「元に戻す（Ctrl + Z）」で戻せます。AIが書き込んだことも、いつもどおり元に戻せます。ここは当日も改めてお話しします。
このテスト用のファイルは保存しなくて大丈夫です。

うまくいかないとき

困りごと試してみること
リボンにアイコンが出てこないPowerPointを完全に閉じて開き直す。それでも出なければ「ホーム」→「アドイン」→「マイアドイン」から探す
Excelには出るのにPowerPointに出ないPowerPointを閉じて開き直してください。それでも出なければ、STEP 1 から入れ直してください
Microsoftアカウントが分からない・持っていない使っているアカウントは PowerPoint の「ファイル」→「アカウント」で確認できます。持っていない場合は、サインイン画面の「作成」から無料で作れます（STEP 0 の③）
会社のPCで、マーケットプレイスが開けない・入れられない会社の管理者がストアを制限している可能性があります。個人のPCで試すか、当日は貼り付け版でご参加ください
サインインできない（Claude版）無料プランになっていないかご確認ください。Claude版は Pro以上 が必要です。無料プランの方は ChatGPT版 をどうぞ
APIキーを求められた（ChatGPT版）サインイン画面で「API キーを使用」を押しています。パネルをいったん閉じて開き直し、黒い「ChatGPT で続行」のほうを押してください
名前の似た別のアドインを入れてしまった「マイアドイン」から削除して、名前が「ChatGPT」だけ・提供元が OpenAI のものを入れ直してください
途中で止まった・上限と言われた（ChatGPT版）無料プランの利用量の上限です。当日は貼り付け版に切り替えれば大丈夫です

5分やってみて解決しなければ、それ以上は粘らなくて大丈夫です。当日は開始から10分ほどのところで一度「アイコンが出ていますか」とだけ聞きます。出ていない方も、チャットにファイルを貼る形で同じ内容が全部できます。

使うときの注意

当日も改めてお話しします。

  • どちらもまだ新しい機能です。うまく動かないことも、間違えることもあります。とくにPowerPoint版のChatGPTはベータで、テンプレートやアニメーション、凝った書式は思いどおりにならないことがあります
  • AIが書き込んだ内容は、PowerPointの「元に戻す（Ctrl + Z）」で戻せます
  • 今回、自分の仕事のファイルは使いません。こちらからお送りする練習用のスライド1枚だけを使うので、機密の心配はいりません
  • 大事なファイルで試すときは、コピーを作ってからにしてください
